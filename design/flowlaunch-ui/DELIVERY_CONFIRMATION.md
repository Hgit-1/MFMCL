## 🎨 设计决策记录

### 品牌标识
- **名称**: FlowLaunch（流启）
- **理念**: 流畅、自然、随需而动
- **Logo**: 简化的"FL"字母 + 渐变色（蓝→紫）
- **主色调**: #2563EB（品牌蓝）
- **次要色**: #7C3AED（紫色）

### 设计方向选择
**选择方向C - 智能情境切换**

**理由**:
1. 最符合"新手容易上手，熟练用户仍然高效"的原则
2. 降低认知负担，减少导航层级
3. 界面随用户状态自动演化
4. 新手看到引导，熟练用户看到快速启动

**其他方向**:
- 方向A（游戏商店模式）- 内容优先，但管理效率较低
- 方向B（实例管理中心模式）- 专业但对新手不够友好

### 技术栈选择
**选择 React + TypeScript + Vite**

**理由**:
1. React 18 - 现代化、生态成熟
2. TypeScript 5 - 类型安全、开发体验好
3. Vite 5 - 构建快速、热重载流畅
4. CSS Modules - 样式隔离、易维护

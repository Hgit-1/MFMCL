## 🎨 设计理念

### 品牌标识
- **名称**: FlowLaunch（流启）
- **理念**: 流畅、自然、随需而动
- **Logo**: 简化的 "FL" 渐变字母组合
- **配色**: 品牌蓝 + 紫色强调

### 核心特性
1. **智能情境切换** - 界面随用户状态自动调整
2. **新手友好** - 首次使用有引导，操作有反馈
3. **高效管理** - 多实例清晰展示，一键启动
4. **可扩展性** - 完整的插件系统，像 VSCode 一样

## 🎯 设计亮点

### 1. 可持续性 ✨
- **CSS 变量驱动** - 修改一处，全局生效
- **CSS Modules** - 样式隔离，无全局污染
- **TypeScript** - 类型安全，减少错误
- **组件化** - 高度复用，易于维护

### 2. 可插件修改 ✨
```typescript
const plugin: Plugin = {
  hooks: {
    onInstanceCreate: (instance) => {/* 自定义逻辑 */},
    customViews: [{/* 自定义视图 */}],
    themeOverrides: {/* 覆盖主题 */}
  }
};
```

- 下载中 → 进度展示（状态可见）

## 二、设计理念与核心决策

### 1. 智能情境切换（方向C）
**决策理由**:
- 新手首次使用看到引导，不是空界面
- 有游戏后自动切换到快速启动中心
- 无游戏时提供明确的创建入口
- 降低认知负担，减少导航层级

**实现方式**:
- 基于状态的条件渲染
- `AppContext` 枚举所有情境
- 平滑的视觉过渡

### 2. 品牌与视觉
**品牌名称**: FlowLaunch（流启）
- "Flow" 代表流畅体验
- "Launch" 明确启动器身份

**Logo**: 简化的 "FL" 字母组合
- 渐变色（蓝到紫）象征现代感
- 圆角矩形背景适配各种场景

**色彩策略**:
- 主色调：品牌蓝 (#2563EB)
- 次要色：紫色 (#7C3AED)
- 语义化：成功绿、警告橙、危险红
- 深色主题：减少饱和度，提高可读性

### 3. 信息架构
**持久导航**（侧边栏）:
- 游戏库（带数量徽章）
- 内容商店
- 下载任务（带进行中徽章）
- 账户状态
- 设置

**主内容区**:
- 根据情境动态切换
- 保持一致的头部结构
- 空状态有明确引导

### 4. 插件化架构
**设计目标**: 像 VSCode 一样可扩展

**扩展点**:
- `onInstanceCreate/Launch` - 生命周期钩子
- `customViews` - 注入自定义视图
- `themeOverrides` - 覆盖主题变量
- `backgroundProviders` - 自定义背景

**实现方式**:
```typescript
interface Plugin {
  id: string;
  hooks: PluginHooks;
}
```

### 5. 响应式与适配
**窗口尺寸**:
- 最小支持：1024×720
- 推荐：1280×900
- 宽屏：1440×900+

**适配策略**:
- 网格自动收缩（auto-fill minmax）
- 小窗口单列布局
- 侧边栏固定宽度（240px）
- 主内容区弹性伸缩

## 五、技术亮点

### 1. CSS Modules 隔离
每个组件有独立的 `.module.css`，避免全局污染：
```tsx
import styles from './Button.module.css';
<button className={styles.button}>
```

### 2. 语义化 CSS 变量
所有颜色、间距、圆角都用变量定义：
```css
var(--color-primary-500)
var(--space-base)
var(--radius-base)
```
修改一次，全局生效。

### 3. TypeScript 类型安全
完整的类型定义，避免运行时错误：
```typescript
interface GameInstance {
  id: string;
  name: string;
  status: 'ready' | 'installing' | 'error';
  // ...
}
```

### 4. 可访问性内置
- 焦点环自动显示（`:focus-visible`）
- 键盘导航（Tab、Enter、Escape）
- 语义化 HTML（`role="dialog"`, `aria-label`）
- 减少动效支持（`prefers-reduced-motion`）

### 5. 插件系统预留
清晰的接口定义，便于后续扩展：
```typescript
interface Plugin {
  hooks: {
    onInstanceCreate?: (instance) => void;
    customViews?: CustomView[];
  }
}
```

## 六、如何修改

### 改变品牌色
**文件**: `styles/globals.css`
```css
:root {
  --color-primary-500: #YOUR_COLOR;  /* 改这里 */
}
```

### 添加新页面
1. 在 `types.ts` 添加新的 `AppContext`
2. 在 `App.tsx` 的 `nav` 添加导航按钮
3. 在 `main` 添加条件渲染逻辑

### 修改组件样式
**例：改变按钮圆角**
```css
/* components/Button.module.css */
.button {
  border-radius: 20px;  /* 原来是 var(--radius-sm) */
}
```

### 创建新组件
1. 复制 `Button.tsx` 作为模板
2. 修改逻辑和样式
3. 导出并在需要的地方导入

## 📝 关键决策说明

### 为什么选择方向C（智能情境切换）？
- **新手友好**: 首次使用看到引导，不是空白界面
- **高效**: 有游戏后自动切换到快速启动，减少点击
- **灵活**: 同一空间承载不同任务，不需要记忆复杂导航
- **可扩展**: 可以根据更多情境添加新模式

### 为什么提供 React 源码而非 Figma？
- **工具限制**: 无法生成真实的 Figma 原生文件
- **更适合开发**: 源码可以直接演化为产品，不需要重新实现
- **更真实**: 状态管理、交互、响应式都是真实的，不是模拟
- **更灵活**: 开发者可以直接修改代码，而不是对照设计稿

### 为什么使用 CSS Modules？
- **样式隔离**: 避免全局样式冲突
- **易于维护**: 组件和样式在同一目录
- **类型安全**: TypeScript 可以检查类名
- **性能优化**: 只加载需要的样式

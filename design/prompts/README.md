# 给 Opus 的提示词

当前推荐只使用 [`OPUS-PROMPT.md`](OPUS-PROMPT.md)。复制其中分隔线之后的全部内容，直接交给 Opus 即可。

该版本遵循最终确认的分工：这里只负责明确需求、执行顺序、原生交付边界和验收标准；具体品牌、风格、布局、控件、动效以及 UI 制作都由 Opus 负责。

## 已检查的可用性

- 需求以用户任务组织，不钉死品牌、主色或导航布局。
- PCL2 只作为功能成熟度愿景，不允许读取或复刻其视觉与界面代码。
- 原版、带加载器游戏、模组和整合包的安装、启动及异常路径有明确范围。
- 正版授权、平台受限资源、日志隐私、备份恢复和取消边界彼此一致。
- `.fig` 优先，但允许选择用户接受的其他原生格式；只要求可靠交付一种。
- 先验证工具写入与导出能力，再大量制作；网页、代码、截图和普通 ZIP 不冒充原生工程。
- 定义制作顺序、分批规则与十项走查任务，降低只生成首页或只有构思没有文件的风险。

## 验证边界

这里完成的是文本一致性与任务可执行性检查，没有在 Opus 中实跑，也没有验证 Opus 账户、额度、上下文或外部设计工具权限。任何提示词都不能替代实际的设计工具写入和导出能力。

同目录的 `01-master-prompt.md`、`02-staged-prompts.md`、`03-acceptance-prompt.md` 是较早的 Figma 专项扩展材料，不必一起发送。它们的交付约束比最新版更偏向 Figma；如需摘用，以 `OPUS-PROMPT.md` 的范围和格式优先级为准。
